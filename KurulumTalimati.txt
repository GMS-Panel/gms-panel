Bu belge, GMS Panel kurulumu oncesinde yapilmasi gereken
Alma Linux minimum sistem hazirligini adim adim anlatmaktadir.


----------------------------------------------------------------
BOLUM 1: MINIMUM SISTEM GEREKSINIMLERI
----------------------------------------------------------------

İşletim Sistemi : Alma Linux 9.x (Minimal Install)
CPU              : En az 1 core (2 core onerilir)
RAM              : En az 1 GB (2 GB onerilir)
Disk             : En az 20 GB
Network          : Statik IP (DHCP onerilmez)
Internet         : Zorunlu (paket indirme ve SSL icin)


----------------------------------------------------------------
BOLUM 2: ALMA LINUX 9 KURULUMU
----------------------------------------------------------------

1. Alma Linux 9 ISO'sunu indirin:
   https://almalinux.org/get-almalinux/
   Dosya: AlmaLinux-9-latest-x86_64-minimal.iso

2. ISO'yu VMware/Hyper-V/Sunucuya yukleyin ve baslatın.

3. Kurulum ekraninda asagidaki ayarlari yapin:

   [Dil Secimi]
   - Istediginiz dili secin (Turkce desteklenmeyebilir)
   - English (United States) onerilir

   [Zaman Dilimi - Time & Date]
   - Europe/Istanbul secin

   [Yazilim Secimi - Software Selection]
   - "Minimal Install" secin
   - Sag tarafta hicbir ek paket secmeyin
   - "Standard" secenegini de isareletemyin

   [Disk Ayarlari - Installation Destination]
   - Diski secin
   - "Automatic" partitioning onerilir
   - En az 20 GB alan olmali

   [Network Ayarlari - Network & Hostname]
   - Ag adaptorunu aktif edin (ON konumuna getirin)
     DIKKAT: Varsayilan olarak OFF gelir, unutmayin!
   - "Configure" tiklayin
   - IPv4 Settings sekmesine gecin
   - Method: "Manual" secin
   - Add tiklayin ve bilgileri girin:
     Address  : Sunucunuzun IP adresi
     Netmask  : Alt ag maskesi (ornek: 255.255.255.248)
     Gateway  : Ag gecidi
   - DNS Servers: 8.8.8.8,8.8.4.4
     DIKKAT: Bu alani bos birakmayın, kurulum sonrasi
             paket indirme islemleri basarisiz olur!
   - Save tiklayin
   - Hostname: istediginiz bir isim yazin (ornek: panel)

   [Root Sifresi - Root Password]
   - Guclu bir sifre belirleyin
   - NOT ALIN, unutmayin!
   - ONEMLI: "Allow root SSH login with password"
     kutucugunu ISARETLEYIN! Isaretlenmezse PuTTY ile
     root girisi yapilamaz.

   [Kullanici - User Creation]
   - Bu adimi ATLAYIN, GMS Panel kendi kullanicisini olusturur

4. "Begin Installation" tiklayin ve kurulumun bitmesini bekleyin.

5. Kurulum bitince "Reboot System" tiklayin.


----------------------------------------------------------------
BOLUM 3: KURULUM SONRASI ILK AYARLAR
----------------------------------------------------------------

Sunucu yeniden basladiktan sonra asagidaki adimlari uygulayın.
Bu islemler icin sunucuya fiziksel veya konsol erisiminiz olmali.

-- ADIM 1: Root ile giris yapin --

   Kullanici adi : root
   Sifre         : Kurulumda belirlediginiz sifre


-- ADIM 2: Ag baglantisini test edin --

   ping -c 4 8.8.8.8

   Yanit geliyorsa internet baglantisi var demektir.
   Gelmiyorsa ag ayarlarinizi kontrol edin:

   ip addr show
   ip route


-- ADIM 3: DNS kontrolu yapın (ONEMLI) --

   ping -c 2 google.com

   "Name or service not known" hatasi aliyorsaniz
   DNS ayari eksik demektir. Asagidaki komutla duzeltın:

   echo "nameserver 8.8.8.8" > /etc/resolv.conf
   echo "nameserver 8.8.4.4" >> /etc/resolv.conf

   Tekrar test edin:
   ping -c 2 google.com

   NOT: GMS kurulum scripti DNS'i kalici hale getirecektir.
        Bu adim sadece scripti indirmek icin gereklidir.


-- ADIM 4: PuTTY ile baglanin --

   Artik PuTTY veya SSH ile root olarak baglanabilirsiniz.
   Kurulum adimlari sirasinda "Allow root SSH login with
   password" kutucugunu isaretlediyseniz direkt baglanir.

   Isaretlemediyseniz asagidaki komutu konsol uzerinden
   calistirin, sonra PuTTY ile baglanin:

   sed -i 's/^#PermitRootLogin.*/PermitRootLogin yes/' /etc/ssh/sshd_config
   echo "PermitRootLogin yes" >> /etc/ssh/sshd_config
   systemctl restart sshd


-- ADIM 5: SELinux durumunu kontrol edin --

   getenforce

   NOT: GMS kurulum scripti SELinux'u otomatik kapatacaktir.
        Manuel kapatmak isterseniz:

   setenforce 0
   sed -i 's/^SELINUX=.*/SELINUX=disabled/' /etc/selinux/config


-- ADIM 6: Sistem saatini kontrol edin --

   timedatectl status

   Saat yanlis ise:
   timedatectl set-timezone Europe/Istanbul
   timedatectl set-ntp true


----------------------------------------------------------------
BOLUM 4: GMS PANEL KURULUMU
----------------------------------------------------------------

Yukaridaki adimlar tamamlandiktan sonra PuTTY ile
sunucunuza baglanin ve asagidaki komutu calistirin:

   curl -O https://raw.githubusercontent.com/GMS-Panel/gms-panel/main/gms-kur.sh
   bash gms-kur.sh

NOT: Minimal Install'da wget kurulu gelmez, curl kullanin.

Script otomatik olarak:
- DNS'i kalici hale getirir
- Sistemi kontrol eder, eksikleri duzeltir
- Gerekli bilgileri sorar
- Nginx, PHP (7.4-8.4), MariaDB 11.4 kurar
- Panel ve site yapisini olusturur
- SSL sertifikasi alir (opsiyonel)


----------------------------------------------------------------
BOLUM 5: SIKCA SORULAN SORULAR
----------------------------------------------------------------

S: PuTTY ile baglanamiyorum, "Access denied" hatasi aliyor.
C: Kurulum sirasinda "Allow root SSH login with password"
   kutucugunu isaretlemis olmaniz gerekir. Isaretlemediyseniz
   ADIM 4'teki SSH Root izin komutlarini uygulayın.

S: "Network unreachable" hatasi aliyorum.
C: Ag ayarlarini kontrol edin:
   nmcli con show
   nmcli con up <baglanti_adi>

S: "Could not resolve host" hatasi aliyorum.
C: DNS ayari eksik. ADIM 3'u uygulayın:
   echo "nameserver 8.8.8.8" > /etc/resolv.conf
   echo "nameserver 8.8.4.4" >> /etc/resolv.conf

S: Kurulum scripti indirme basarisiz oluyor.
C: Once DNS testini yapin (ADIM 3). Sonra curl ile indirin:
   curl -O https://raw.githubusercontent.com/GMS-Panel/gms-panel/main/gms-kur.sh
   wget Minimal Install'da kurulu gelmez, curl kullanin.

S: Disk alani yetersiz hatasi aliyor.
C: Minimum 20 GB disk alani gereklidir.
   df -h komutu ile disk durumunu kontrol edin.

S: RAM yetersiz hatasi aliyor.
C: Minimum 1 GB RAM gereklidir.
   free -h komutu ile RAM durumunu kontrol edin.
